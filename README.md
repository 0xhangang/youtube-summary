# 📺 유튜브 상세 요약

관심 유튜브 채널의 자동 요약을 모아 두는 정적 아카이브입니다.
화자의 말투와 뉘앙스를 그대로 살린 상세 요약을 날짜별로 보관하고, 모바일에서 읽기 좋게 보여 줍니다.

- 사이트: https://0xhangang.github.io/youtube-summary/
- 빌드 과정 없음. `index.html` + `assets/` + `data/*.json` + `s/*.html` 만으로 동작합니다 (`.nojekyll`).
- **운영 규칙 원장: [`RULES.md`](RULES.md)** · 담당 채널 배정표: [`data/radar_assign.json`](data/radar_assign.json) (검증: `python3 scripts/check_assign.py`)

## 요약 기준 (17차 최종 확정)

상세 기준은 [`RULES.md` §2](RULES.md)가 정본이고, 실제 적용 예시는 [`sample-alsangmu.html`](sample-alsangmu.html)입니다.

| 항목 | 기준 |
| --- | --- |
| 소제목(`h`) | 지엽적 숫자·사례 대신 구간 전체를 관통하는 핵심 원칙을 담은 **명사형(핵심 구절)**. `~니다` 체 고정 문구 없이 반말·존댓말 채널 모두에 어울리고, 아래 문단과 1:1로 연결 |
| 문단(`p`) | 한 문단 = 한 논점(2~3문장). 쉼표로 3~4줄 이어지는 문장은 마침표로 끊고, 사실과 해석이 갈리는 경계에서 문단을 나눔 |
| 볼드(`**...**`) | 객관적 재료·주제어. 나열 종목·사례도 핵심 재료면 볼드, 비교·대조·전환 축의 주어는 빠짐없이, 문단당 첫 등장 1회, 화자 판단 제외 |
| 형광펜(`==...==`) | 화자의 핵심 결론·투자 원칙·결정적 판단/근거만. 갯수·비율 제한 없음, 한 문단 최대 1곳, 주어+핵심 서술어가 살아 있는 완결 단위 |

## 화면 기능

| 기능 | 설명 |
| --- | --- |
| 상단 허브 | 제목과 부제(지금 보는 범위 · 편수). 오른쪽에 `정렬`(최신순 ↔ 오래된순)·`테마`(라이트 ↔ 다크)·`동기화` 세 버튼. 스크롤하면 자연스럽게 올라가고 자동 숨김은 없음 |
| 탭 7개 | `목차` · `날짜` · `분류` · `채널` · `읽음` · `좋아요` · `검색`. 목차·분류·채널·읽음·좋아요·검색 탭에는 개수 배지가 붙고, 날짜 탭은 고른 날짜(`11월 28일` 등)를 이름 자리에 보여 준다. 열린 탭을 다시 누르면 접힘 |
| 날짜 탭 | 월간 달력 — `전체 보기` + `◀ 2026년 11월 ▶` 월 이동, 일~토 7열에 날짜 숫자와 그날 편수를 함께 표시하고 편수에 따라 에메랄드 강약(히트맵 1~4단계). 앱을 열면 `전체 보기`(모든 날짜)로 시작하고 달력은 오늘이 있는 달을 먼저 띄움(그 달에 자료가 없으면 최근 달) |
| 분류 칩 | 영상 주제에 딱 맞는 1단어(`categoryLabel`) — 데이터에서 자동 생성, 개수 제한 없음 |
| 채널 칩 | 편수 많은 순으로 `감시 중` 채널을 먼저, 그 아래 `단발 요약` 채널을 구분선으로 나눠 표시 |
| 목차 | 지금 화면에 있는 요약 전체의 목차(번호 · 채널 · 제목). 누르면 그 카드로 이동해 잠깐 강조 표시 |
| 읽음 탭 | 읽음 표시한 요약을 **모든 날짜에서 모아** 목록으로 보여 줌 |
| 좋아요 탭 | 좋아요한 요약을 **모든 날짜에서 모아** 목록으로 보여 줌 |
| 검색 | 제목·채널·분류·본문 전체를 대소문자 무시하고 검색. 검색은 모든 날짜를 대상으로 함 |
| 읽음·좋아요·공유 | 카드마다 `읽음` `좋아요` `공유` 버튼. 기본 전체 보기에서는 읽은 카드가 목록에서 빠지고, 방금 표시한 카드는 그 자리에서 흐려짐. 읽음·좋아요·검색·단일 카드 화면에서는 흐림 없이 선명하게 보여 줌. `공유`는 웹 공유 API(없으면 클립보드 복사)로 `s/{videoId}.html` 링크와 `📺 [채널] 제목`을 내보냄 |
| 카드 스와이프 | 카드 본문 어디서나 **오른쪽으로 밀면 읽음/안읽음**, **왼쪽으로 밀면 좋아요** 토글. 화면 좌우 가장자리 28px 안에서 시작한 터치는 OS 뒤로가기 제스처와 겹치지 않게 무시하고, |dx| > 14 이고 |dx| > |dy| × 1.5 일 때만 가로 스와이프로 들어감(세로로 판별되면 그 터치는 끝까지 스크롤). 80px를 넘기면 배지가 확정 표시(`.is-armed`)로 커지고, 손을 떼면 토글 후 0.26초에 원위치. 배지는 카드 세로 한가운데가 아니라 손가락 높이에 붙고, 버튼·링크·표(`.tbl-wrap`) 안에서 시작하면 동작하지 않음 |
| 동기화 | 읽음·좋아요를 **비공개 GitHub Gist**에 보관해 기기·브라우저 사이를 맞춤. `gist` 권한 classic 토큰을 한 번 넣으면 Gist를 자동으로 찾거나 새로 만들고, 변경 1.5초 뒤 자동 푸시, 화면으로 돌아올 때 30초 간격으로 확인. 영상별 마지막 변경이 이기는 방식으로 병합. 토큰은 `localStorage`에만 저장되고 코드·Gist에는 남지 않음(연동하지 않은 방문자는 네트워크 요청 없이 로컬 저장만 사용) |
| 썸네일 | 카드마다 16:9 썸네일. 누르면 유튜브 원문이 새 탭으로 열림. `maxresdefault → sddefault → thumbnail 필드 → hqdefault → mqdefault` 순으로 시도하고(120px 이하 자리표시 이미지는 건너뜀), 전부 실패하면 카드에서 그림만 빠지고 글은 그대로 |
| 메타 줄 | 상대시간(`19시간 전`)과 발행 시각(`11. 28. 03:24`, 한국시간), 채널명·분류 칩. 좋아요한 카드는 분류 칩 옆에 작은 하트 칩(`.liked-chip`)이 붙음. 아바타와 채널명을 누르면 채널 페이지로 이동 |
| 목록 지연 렌더 | 카드는 처음 20편만 그리고, 스크롤이 내려가면 20편씩 이어서 그림(`IntersectionObserver`) |
| 단일 카드 링크 | `?v=VIDEO_ID`(또는 `#v-VIDEO_ID` 앵커)로 한 편만 크게 보기. 이때 상단 허브는 숨고 `전체 요약 보기`·`테마` 버튼만 남음 |
| 카드 일체형 읽기 바 | 카드마다 제목칸(`.yt-info`) 바로 아래에 40px 1줄 바(`.card-sticky` 안의 `.card-bar`)를 두고 `position: sticky; top: 0`(높이 40px + `margin-bottom: -40px`로 흐름을 차지하지 않음)으로 붙인다. 카드 제목칸이 화면 위로 완전히 사라지는 순간부터 카드 바닥까지, 그 카드의 1px 테두리 안쪽 폭·같은 바탕(`--surface-2`) 그대로 따라 내려오고(`sticky`가 동작하도록 `.card`는 `overflow: hidden` 대신 `overflow: clip`), 다음 카드가 올라오면 카드 바닥과 함께 밀려 올라간다. 좌우 테두리·바깥 그림자 없이 아래쪽 1px 선만 있고, 내용은 `채널 아바타 채널명 영상 제목`(사이 구분은 8px 여백) 한 줄. 오른쪽 ↑ 아이콘을 누르면 그 카드 맨 위로 부드럽게 올라간다 |
| 맨 위로 | 600px 넘게 스크롤하면 오른쪽 아래에 ↑ 버튼이 나타남 |
| 탭 패널 스크롤바 | 탭으로 연 목록이 다섯 줄을 넘치면 오른쪽에 늘 보이는 4px 짜리 트랙·썸을 그려 준다. 썸 높이는 `보이는 높이 / 전체 높이` 비율(최소 24px)이라 목록이 얼마나 남았는지 바로 보이고, 스크롤하면 부드럽게 따라간다. OS가 그리는 네이티브 스크롤바(삼성 인터넷에서 스크롤을 멈추면 사라지는 것)는 `scrollbar-width: none`/`::-webkit-scrollbar { display: none }`로 감춘다 |
| 전체 페이지 스크롤바 | 본문 페이지 스크롤바도 메뉴 패널과 똑같은 4px 트랙·썸(`.page-track`·`.page-thumb`)을 화면 우측 끝(`right: 3px`)에 `position: fixed`(z 35·`pointer-events: none`)로 그려 통일했다. 내용이 `innerHeight + 4`보다 길 때만 보이고 썸 높이는 `보이는 높이 / 전체 높이`(최소 28px), 스크롤·리사이즈·본문 추가(`ResizeObserver` on `body`) 때 다시 계산한다. 네이티브 페이지 스크롤바는 `html, body { scrollbar-width: none }`/`::-webkit-scrollbar { display: none }`로 감추되 `window` 스크롤 구조(삼성 인터넷 주소창 숨김·sticky 허브·읽기 바)는 그대로 둔다 |
| 다크 모드 | 우측 상단 토글, `localStorage['yts.theme']`에 저장. 첫 방문은 OS 설정을 따름 |

### 읽기 화면 규칙

- 본문은 카드 안에서 최대 `--measure: 44em` 폭으로 가운데 정렬해 한 줄 길이를 조절합니다.
- 본문 글자 16px·줄높이 1.75, 소제목 모바일 18.5px·굵기 750(600px 이상 20px)·위 여백 34px·아래 10px·구분선 없음, 문단 사이 14px, `word-break: keep-all` — 긴 시청형 줄글을 오래 읽기 좋은 값입니다.
- `**굵게**`는 배경 없는 굵은 글씨 **650**(형광펜 안의 주제어는 700)으로, `==형광펜==`은 글자 아래 45%만 칠하는 에메랄드 하프 형광펜(`<mark class="hl-half">`)으로 그립니다. 소제목은 제목 첫 줄 왼쪽에 4px 단색 에메랄드 막대(두 줄이어도 첫 줄에만)로 구분합니다.
- **문단 경계:** 16차 표준 글(레거시 블록 없이 `h`·`p`만이고 `==형광펜==`을 쓴 글, 또는 2026-11-28 22:00 KST 이후 적재분)은 저장된 문단 경계를 그대로 그립니다. 구형 글만 `splitParagraph()`가 210자 이상 긴 문단을 2~3문장 단위로 자동 분할합니다(형광펜 짝이 끊기지 않도록 자르는 동안 토큰으로 가림). 그래서 새 요약은 저장한 문단이 화면에서도 그대로 유지됩니다.
- 라이트/다크 토큰은 `assets/style.css` 맨 위 `:root` / `[data-theme="dark"]` 한 곳에서만 바꿉니다.

브라우저에서 `index.html`을 파일로 직접 열면 `fetch`가 막혀 데이터가 보이지 않습니다. 로컬 확인은 아래처럼 서버로 열어 주세요.

```bash
python3 -m http.server 8000 --directory .
# http://localhost:8000
```

## 데이터 형식

### data/index.json

```json
{
  "site": "📺 유튜브 상세 요약",
  "updatedAt": "2026-11-28T23:10:00+09:00",
  "dates": [
    {
      "date": "2026-11-28",
      "label": "2026년 11월 28일 토요일",
      "count": 6,
      "file": "data/2026-11-28.json"
    }
  ]
}
```

`dates`는 최신 날짜가 먼저 오도록 정렬합니다. `count`는 그날 요약 편수입니다.

### data/YYYY-MM-DD.json

```json
{
  "date": "2026-11-28",
  "label": "2026년 11월 28일 토요일",
  "updatedAt": "2026-11-28T04:10:08+09:00",
  "summaries": [
    {
      "id": "NEz--_o9HWs",
      "videoId": "NEz--_o9HWs",
      "url": "https://www.youtube.com/watch?v=NEz--_o9HWs",
      "channel": "내일은 투자왕 - 김단테",
      "category": "stock",
      "categoryLabel": "증시",
      "title": "트렌드포스 \"메모리 슈퍼사이클 끝\" (15:00)",
      "publishedAt": "2026-11-28T03:24:53+09:00",
      "duration": 901,
      "thumbnail": "https://i.ytimg.com/vi/NEz--_o9HWs/hqdefault.jpg",
      "channelId": "UCKTMvIu9a4VGSrpWy-8bUrQ",
      "addedAt": "2026-11-28T04:10:08+09:00",
      "blocks": [
        { "type": "h", "text": "추수감사절 다음 날, 조기 마감을 앞두고 나스닥은 1.92% 오르고 있습니다" },
        { "type": "p", "text": "새벽의 남자 김단테입니다, 오늘도 또 왔습니다. … 오늘은 미국 **추수감사절** 다음 날이라 **나스닥**이 일찍 끝나는데, 마감을 앞둔 지금 1.92% 오르고 있습니다." },
        { "type": "p", "text": "엔비디아는 중국으로 반출이 금지됐던 **블랙웰 칩**이 중국에서 발견됐고 … ==중국에서 발견된 블랙웰 칩 기사가 엔비디아 발목을 잡은 것이라고 저는 보고 있습니다.==" }
      ]
    }
  ]
}
```

- `videoId` — 고유 키. 읽음·좋아요 표시도 이 값을 씁니다.
- `category` — 그 단어의 영문 슬러그(`stock`·`coin`·`trading`·`macro`·`ai`·`tech`·`realestate`·`economy`·`finance`·`tax`·`politics`·`trend`·`mind`·`health`·`review`·`game` 등). `categoryLabel`이 없으면 자동 라벨을 씁니다. **두 단어를 `·`으로 묶는 라벨은 쓰지 않습니다**(RULES.md §2-3).
- `blocks` — 본문. 새 요약은 `type`이 `h`(소제목)·`p`(문단) 두 종류만 씁니다.
본문 텍스트의 `**굵게**`는 배경 없는 굵은 글씨로, `==형광펜==`은 45% 하프 형광펜으로 변환되고 나머지는 그대로 출력됩니다(HTML 태그 무시). 예전 글의 `ul`·`callout`·시각화 블록은 계속 그려집니다(RULES.md §4-1).
- `summaries` 배열 순서가 화면 순서입니다. 그날 안에서는 도착 순서대로 뒤에 붙입니다.
- 선택 필드: `kind`(`video`/`short`/`live`), `channelId`, `publishedAt`, `duration`, `thumbnail`.

### 업로드 시각 · 길이 · 썸네일

| 필드 | 형식 | 화면 표시 |
| --- | --- | --- |
| `publishedAt` | 유튜브 표기 그대로. `2026-11-28T03:24:53+09:00`, `...Z`, `2026-11-28 03:24` | `11. 28. 03:24` (항상 한국시간으로 환산, 해가 다르면 연도까지) + 상대시간 `19시간 전` |
| `duration` | 초 단위 정수(`901`) 또는 시계 표기(`2:27`, `1:12:22`) | 데이터에만 보관(현재 카드에는 표시하지 않음) |
| `thumbnail` | 이미지 주소. 비우면 `https://i.ytimg.com/vi/{videoId}/hqdefault.jpg` | 카드 상단 16:9 썸네일 |

썸네일은 `maxresdefault.jpg`를 먼저 시도하고, 없으면 `sddefault.jpg` → `thumbnail` 값 → `hqdefault.jpg` → `mqdefault.jpg` 순으로 내려갑니다.
다른 곳의 이미지 주소를 넣으면 그 주소를 가장 먼저 씁니다. `publishedAt`이 없으면 시각·상대시간 자리가 그냥 빠지고 카드는 그대로 보입니다.

## 새 요약 붙이기 (스케줄 액션이 쓰는 방법)

`scripts/add_summaries.py`가 날짜 파일에 요약을 붙이고 `index.json`을 다시 만듭니다.

```bash
# 1) 새 요약을 JSON으로 쓴다 (blocks 배열 — h·p 두 종류만)
cat > /tmp/new.json <<'JSON'
{
  "date": "2026-11-28",
  "summaries": [
    {
      "videoId": "AAAAAAAAAAA",
      "channel": "알상무",
      "category": "stock",
      "categoryLabel": "증시",
      "title": "지표추적자 1128",
      "publishedAt": "2026-11-28T09:02:00+09:00",
      "duration": "1:12:22",
      "blocks": [
        { "type": "h", "text": "코스닥은 650에서 담고 666 돌파에 먹고 빠지는 자리입니다" },
        { "type": "p", "text": "코스닥을 **650**에서 분할 매수해서 **666** 돌파를 확인하고 들어갑니다. ==지금은 추세가 완전히 돌았다고 보기엔 이릅니다.==" }
      ]
    }
  ]
}
JSON

# 2) 데이터에 반영 (같은 videoId는 기본적으로 건너뜀, --replace로 갱신)
python3 scripts/add_summaries.py /tmp/new.json

# 3) 확인 후 커밋·푸시 — Pages가 1분 안에 자동 반영
git add -A && git commit -m "요약 추가: 2026-11-28 (N편)" && git push
```

`text` 필드에 줄글 하나로 넣을 수도 있습니다(이때 `##`/`###` → 소제목, `-`/`*` → 불릿, `>` → 강조 상자, 빈 줄로 나뉜 덩어리 → 문단). 다만 새 요약 표준은 순수 `h`+`p`이므로 `blocks`로 쓰는 쪽을 권합니다.
편수·날짜 집계는 스크립트가 다시 계산하므로 손으로 `index.json`을 고칠 필요가 없습니다.
`publishedAt`·`duration`은 형식을 맞춰 저장하고(`2026-11-28 09:02` → `2026-11-28T09:02:00+09:00`, `1:12:22` → `4342`),
`thumbnail`을 비우면 `hqdefault.jpg` 주소를 채웁니다.

수동으로 JSON을 직접 고쳐도 됩니다. 새 날짜 파일을 추가했다면 `data/index.json`의 `dates`에 항목을 넣어 주세요.
